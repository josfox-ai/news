# Specification 2.0.0 under IANA review, kernels 2.1.0 on npm and PyPI, the JOS Omni hub opens

Date: 2026-11-06 · Charism: JOS community (open standard and reference tools); the last section concerns JOSFOX distributions.

If you write or run `.jos` documents, three things are now in place at once: a stable 2.0.0 text to cite, a media type registration in progress at IANA, and reference kernels in two languages that you can install without any account and run offline. This item lists each with its source.

## Details

**The specification is at 2.0.0 and its media type is before IANA.** The current text is tag `v2.0.0` of [josfox-jos/jos-spec](https://github.com/josfox-jos/jos-spec); 1.0.0 remains in force at tag `v1.0.0`. Every valid 1.0.0 document is a valid 2.0.0 document, with one numeric exception documented in `IANA.md` and `CONFORMANCE.md`. The media type `application/vnd.jos+json`, with an optional `version` parameter, is IANA ticket #1460136, status pending. A `.jos` document is data: parsing or validating it must not run anything.

**Two reference kernels, both at 2.1.0, both with zero dependencies.**

- JavaScript: `@josfox/jos-core` 2.1.0 on npm, Node >= 18, 0 dependencies.
  <!-- FACTS.md, "Published packages": row @josfox/jos-core; "Re-collection 2026-11-06": row @josfox/jos-core dependencies -->
- Python: `jos-core` 2.1.0 on PyPI, Python >= 3.10, 0 dependencies.
  <!-- FACTS.md, "Published packages": PyPI paragraph -->

Both kernels passed the specification's document-level test kit at 279 of 279 vectors in the specification's own measurement of 2026-10-22 (made with `jos-core` 2.0.0, offline); that run has not been repeated independently for 2.1.0.
<!-- FACTS.md, "The specification": row Document-level TCK and the "Not verified in this session" note -->

**Command line.** `@josfox/jos` 6.0.1 on npm is the host CLI for the JavaScript kernel; it validates and runs documents of versions 2.1.0, 2.0.0, 1.1.0, 1.0.0 and 0.0.7, offline first.
<!-- FACTS.md, "Published packages": row @josfox/jos; "Re-collection 2026-11-06": row @josfox/jos description -->

```bash
npm install -g @josfox/jos
pip install jos-core
```

**Editor.** The VS Code extension `JOSFOX.josfox-jos` ("JOSFOX - JOS Open Standard") is at 2.1.0 on the Visual Studio Marketplace.

## JOS Omni: a public documentation hub for distributions

[josfox-ai/jos-omni](https://github.com/josfox-ai/jos-omni) is a new public repository that documents platform-specific JOSFOX distributions and their availability, one target at a time. It is documentation, not the implementation. The VS Code extension above is the one distribution whose listing has been observed.
<!-- FACTS.md, "Re-collection 2026-11-06": row josfox-ai/jos-omni; catalog/omni.json public_hub -->

## Not yet

- The product catalog reports 31 platform targets. For them, documentation is published and artifacts are not yet available; their build status is reported by the product team and has not been independently verified.
